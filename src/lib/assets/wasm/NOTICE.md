# Bundled Typst WASM runtime

Typlete bundles the WebAssembly modules from these Apache-2.0 licensed packages so its default browser and server renderers do not depend on a CDN or on package-manager-specific transitive dependency layouts:

- `@myriaddreamin/typst-ts-web-compiler` 0.7.0-rc2
- `@myriaddreamin/typst-ts-renderer` 0.7.0-rc2

Copyright and license terms are provided by the upstream packages and are compatible with Typlete's Apache-2.0 license.
