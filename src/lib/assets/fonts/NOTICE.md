# Bundled Typst font assets

Typlete vendors the default `text` font set used by `@myriaddreamin/typst.ts` 0.7.0-rc2 so normal rendering does not depend on a runtime font CDN.

The files mirror the font families distributed by the Typst `typst-assets` project for the Typst 0.13.1 asset set:

- `LibertinusSerif-*.otf` — Copyright © 2012-2024 The Libertinus Project Authors; SIL Open Font License 1.1.
- `NewCM*.otf` — Copyright © 2019-2024 Antonis Tsolomitis; GUST Font License. The license statement is also embedded in the font metadata.
- `DejaVuSansMono*.ttf` — Bitstream Vera / DejaVu font terms. The copyright and permission notices are embedded in the font metadata.

The font files remain under their respective font licenses; Typlete's Apache-2.0 license does not replace those licenses.
